# astra-reels — мастерская роликов Астры

Только сборка коротких видео: скрипты рендера, генератор музыки, колода.
Ни логики бота, ни подсказок для ИИ, ни значений карт, ни ключей — они
остаются в закрытом репозитории проекта.

Запуск: `python3 tools/reel.py --format signs --out reel.mp4`
Нужны: Python 3, Pillow, numpy, ffmpeg (в системе).
